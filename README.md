* Core objective: Translating foundational Operating Systems and Network Architecture concepts into production-style Infrastructure as Code (IaC) using Terraform and AWS.
* Architecture Highlights: Implements a /16 VPC partitioned into public, private and isolated tiers, secured via NAT Gateway outbound-only egress and strict, chained security groups.
* Current status & Roadmap: Networking, security, and state dependency structures are deployed; active development continues with EC2 compute provisioning, launch templates and automated load balancing.
